Confidentialité

En bref

On ne collecte rien. Pas de compte, pas de formulaire, pas de cookie, pas de mesure d'audience, pas de publicité, pas de traceur. Le jeu tourne entièrement dans ton navigateur : ce que tu fais dans le jeu ne quitte pas ton appareil.

Hébergement

Le site est hébergé par GitHub Pages. Comme tout hébergeur, GitHub peut enregistrer des données techniques (par exemple l'adresse IP et le type de navigateur) pour la sécurité et le bon fonctionnement du service. Voir la déclaration de confidentialité de GitHub.

Cookies

Aucun cookie n'est déposé par ce site. Il n'y a donc rien à accepter ni à refuser.

Liens vers d'autres sites

Les liens vers Patreon, Twitch, Discord et GitHub mènent vers des services qui ont leurs propres règles de confidentialité.

Tes droits

Comme ce site ne collecte aucune donnée personnelle, il n'y a rien à consulter, corriger ou supprimer chez nous. Pour toute question, ouvre une issue sur GitHub. Tu peux aussi t'adresser à la CNIL (cnil.fr).
